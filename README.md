# Herramienta de Capacitación Empresarial

Aplicación web desarrollada como apoyo para procesos de capacitación y consulta de información dentro de un contexto empresarial.

## Objetivo

Centralizar material e interacciones de capacitación en una interfaz web sencilla, accesible desde navegador y adaptable a diferentes dispositivos.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Estructura

- `index.html`: interfaz principal.
- `style.css`: estilos de la aplicación.
- `app.js`: lógica e interacción del usuario.
- Recursos gráficos utilizados por la interfaz.

## Valor del proyecto

Este proyecto refleja la construcción de herramientas internas orientadas a mejorar procesos operativos y de formación. Es un ejemplo de cómo una necesidad empresarial puede transformarse en una solución web práctica.

## Buenas prácticas aplicadas

- Separación entre estructura, estilos y lógica.
- Interfaz pensada para uso práctico.
- Organización sencilla para facilitar mantenimiento.

## Estado

Proyecto de práctica aplicada y portafolio. Los recursos o referencias empresariales se conservan únicamente con fines demostrativos; cualquier reutilización debe considerar permisos y tratamiento adecuado de información corporativa.
