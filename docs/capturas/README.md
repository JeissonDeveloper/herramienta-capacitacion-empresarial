# Capturas para el portafolio

Esta carpeta está destinada a evidencias visuales de la herramienta de capacitación empresarial.

## Capturas recomendadas

1. `01-inicio.png` — pantalla principal.
2. `02-contenido-capacitacion.png` — módulo o contenido representativo.
3. `03-interaccion.png` — ejemplo de una interacción de usuario.
4. `04-vista-movil.png` — evidencia del comportamiento adaptable si aplica.

## Privacidad

Evitar información interna, nombres de colaboradores, material confidencial o elementos que no tengan autorización para publicación. Cuando sea necesario, reemplazar contenido por datos demostrativos.
